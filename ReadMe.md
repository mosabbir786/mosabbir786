# 💫 About Me:
About Me<br><br>I am a Cross-Platform Mobile Application Developer with approximately 3.3 years of professional experience in developing, maintaining, and optimising applications using C#, .NET MAUI, Xamarin.Forms, and XAML. I hold a Bachelor of Technology degree in Computer Science Engineering and have hands-on experience building business applications for Android, iOS, and Windows platforms.<br><br>My strongest area is cross-platform mobile application development, with a special focus on responsive and adaptive user interfaces. I enjoy building a single application that looks clean and works smoothly on phones, tablets, kiosks, POS terminals, and Windows desktop screens. I pay close attention to layouts, touch interactions, and screen-size differences so that users get a consistent and comfortable experience on every device.<br><br>During my professional journey, I have worked on enterprise and customer-facing applications, including Point of Sale (POS) systems, self-service kiosks, donation kiosks, webstore applications, and other mobile solutions. My experience includes developing responsive user interfaces, integrating REST APIs, implementing application workflows, troubleshooting production issues, and improving application performance and stability.<br><br>At RocketPOS Ltd., I worked as a .NET MAUI Developer and was the sole front-end mobile engineer, contributing to POS, kiosk, webstore, and donation kiosk applications for retail and restaurant businesses in New Zealand and the GCC region. I was responsible for mobile and desktop UI development, API integration, printer connectivity, customer-facing display functionality, and resolving performance-related issues. I also worked with hardware peripherals such as Epson thermal printers and barcode scanners, helping ensure smooth communication between the applications and connected devices. My work involved improving application startup time, reducing unnecessary API calls, diagnosing crashes, and optimising user interactions, which helped achieve around 99% crash-free stability and performance improvements of up to 80% in some applications. I was also recognised as Employee of the Month in February 2025 for building crash-free applications, optimising performance, delivering ahead of deadlines, and creating responsive and visually polished user interfaces.<br><br>Previously, at Interest Buds Solution, I worked with Xamarin.Forms and .NET MAUI to develop and maintain Android and iOS applications across social and events, food delivery, and enterprise client projects. I gained experience in application migration, production bug fixing, Firebase integration, and maintaining existing applications across different Android versions. I also worked with architectural patterns and development practices such as MVVM, Repository Pattern, Dependency Injection, and Clean Architecture to keep application code organised and maintainable.<br><br>My technical skills include C#, XAML, .NET MAUI, Xamarin.Forms, responsive and adaptive UI design, custom controls, REST API integration, JSON, Firebase Authentication, Realtime Database, Firebase Cloud Messaging, SQLite, Google Maps SDK, payment integrations, debugging, performance profiling, memory management, and crash analysis. I am comfortable working with Visual Studio, Git, Jira, and Agile development processes. I also have experience with application features involving payments, order management, printing workflows, notifications, and real-time status updates.<br><br>One of my key strengths is my ability to investigate existing code, identify the root cause of issues, and improve applications without unnecessarily affecting existing functionality. I focus on writing maintainable code, creating responsive and adaptive user interfaces, handling errors carefully, and delivering a stable user experience. I value teamwork, clear communication, accountability, and continuous learning.<br><br>Alongside my existing development experience, I am interested in expanding my knowledge of modern application development, cloud technologies, and AI-assisted development tools. I am also progressing through networking studies, including CCNA coursework, to strengthen my broader technical understanding.<br><br>I am currently exploring opportunities where I can apply my experience in .NET MAUI, Xamarin.Forms, cross-platform mobile application development, Windows applications, POS and kiosk systems, and application support. I am based in the UAE, available to join immediately, and open to suitable opportunities that match my skills and offer scope for learning and professional growth. My goal is to contribute to a team that values quality, practical problem-solving, collaboration, and long-term product improvement.
